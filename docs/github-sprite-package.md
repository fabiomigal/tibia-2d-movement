# Pacote público de sprites — Batedor de Ruínas

## Release versionada

O pacote de preservação das sprites do Batedor de Ruínas está publicado na release pública [`sprites-batedor-ruinas-v1`](https://github.com/fabiomigal/tibia-2d-movement/releases/tag/sprites-batedor-ruinas-v1), vinculada à ramificação `main` do repositório `fabiomigal/tibia-2d-movement`.

| Arquivo | Conteúdo | Integridade |
|---|---|---|
| `vale-ambar-batedor-ruinas-v1.zip` | Fonte JPEG, 5 atlas 4×4, 80 quadros PNG individuais de 128×128 px, manifesto e pipeline de preparação | `79c5088c66a1b168237d95d968dc2c418e64bbca6438ee82a6499003f329029a` |
| `vale-ambar-batedor-ruinas-v1.zip.sha256` | Checksum do pacote ZIP | Publicado junto à release |

## Proveniência e contrato visual

> A arte foi gerada por Gemini sob comandos do usuário `fabiomigal@gmail.com`; o uso e a distribuição para o Vale de Âmbar foram autorizados pelo autor.

O pacote documenta a ordem de linhas `norte`, `leste`, `sul`, `oeste`, de cima para baixo. Os 80 quadros isolados são reunidos em cinco atlas para os estados de repouso, caminhada, ataque, dano e derrota. O arquivo é mantido como material de preservação e auditoria; o runtime continua usando os atlas publicados no armazenamento estático, sem mudança de carregamento para o jogo ou para o GitHub Pages.
